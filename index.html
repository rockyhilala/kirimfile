Cara menerima file

LANGKAH-LANGKAH:
  1. 01Pastikan HP B terhubung ke hotspot HP A (cek Settings → Wi-Fi).
  2. 02Buka aplikasi BEAM di HP A, pilih file yang ingin dikirim.
  3. 03Di HP B (aplikasi ini), tekan "Mulai Kamera".
  4. 04Arahkan kamera ke QR Code yang muncul di HP A.
  5. 05QR Code balasan akan muncul di HP B — scan dari HP A.
  6. 06File otomatis ditransfer — bisa didownload setelah selesai.
